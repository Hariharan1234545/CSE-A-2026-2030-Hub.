# CSE-A Student Hub
Open `index.html` in a browser to run the demo.

Included:
- Responsive CSE-A themed homepage
- Demo student login
- 5-question C programming quiz
- Instant scoring
- Resource/announcement/planner/leaderboard feature cards

For a real college deployment, connect authentication and a database (e.g. Firebase/Supabase) and add admin controls.
